# Django Project - Интернет-магазин

## 📝 Описание проекта

Учебный проект интернет-магазина, разрабатываемый в рамках курса по Django. Проект представляет собой базовую настройку веб-приложения с двумя страницами: главной и страницей контактов.

## 🚀 Основные возможности

- Главная страница с приветственным содержимым
- Страница контактов с формой обратной связи и контактной информацией
- Адаптивный дизайн на Bootstrap 5
- Чёрное боковое меню с навигацией

## 🛠️ Технологии

- Python 3.14
- Django 6.0.4
- Bootstrap 5.3.8
- SQLite3 (база данных)

## 🔧 Установка и запуск

### 1. Создание и активация виртуального окружения

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```
### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```
### 3. Применение миграций

```bash
python manage.py migrate
```
### 4. Запуск сервера

```bash
python manage.py runserver
```
### 5. Открыть в браузере
http://127.0.0.1:8000/
